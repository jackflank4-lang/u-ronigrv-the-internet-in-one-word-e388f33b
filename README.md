# The Internet in One Word

Entry for the make.fun competition
[u-ronigrv-the-internet-in-one-word-e388f33b](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b):
describe the whole internet in a single word.

## The word

**feral**

Five letters. The internet is feral: wild, untamed, unpredictable, full of
strange creatures doing strange things at 3am. It is funny by itself, it says
something true about the internet as a whole rather than one app or one mood,
and it is not the first obvious word anyone reaches for. It lands in one beat.

## How it works

`main.ts` writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`
when set), and nothing else. The entry is the word and nothing else: no files,
no code, no links.

Run it:

```sh
node main.ts
```
